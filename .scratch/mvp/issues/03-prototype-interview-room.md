# 确定面试房间交互与数字人表现

Type: prototype
Status: resolved
Blocked by:

## Question

最少需要哪些页面和可视状态，才能让候选人清楚地开始面试、理解 AI 当前是倾听/思考/说话，必要时手动结束回答，并在之后查看历史？

## Answer

选择原型 B“沉浸式面试官”作为 MVP 面试房间方向：

- AI 面试官占据中央主舞台，是面试中的视觉主体。
- 候选人的本地摄像头预览作为右上角画中画，明示“仅本地预览”。
- 当前问题、AI 倾听/思考/说话状态与“可直接开口打断”提示覆盖在主舞台上。
- 麦克风、摄像头、“结束回答”和“结束面试”控件放在底部中央。
- 面试进行中不以实时转写为主视图，避免候选人进入“读文字”而非“面对面回答”的心智。
- 原型 C“转写主导工作台”保留为未来 C 端产品方向，不进入当前 MVP。历史回看页仍可展示文字转写。

用户在浏览器原型中两次选择 B。原型作为临时主要资料保存于 [`interview-room-layouts.html`](../../../.superpowers/brainstorm/70591-1787839210/content/interview-room-layouts.html)。
