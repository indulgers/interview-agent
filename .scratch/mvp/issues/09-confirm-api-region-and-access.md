# 确认运行地区与实时语音 API 可用性

Type: grilling
Status: resolved
Blocked by:

## Question

该本机个人应用实际从哪个地区和网络环境运行，用户是否已有在官方支持地区开通计费且可稳定使用的 OpenAI API 账号？如果必须在中国大陆网络中稳定合规运行，则需新增国内实时语音供应商调研票后才能选定架构。

## Answer

应用必须在中国大陆网络环境运行，用户尚未拥有 OpenAI API 账号。因此：

- OpenAI Realtime 不能作为 MVP 主路径。
- 不使用 VPN、非官方代理或转发 API 作为产品依赖。
- 架构选型前必须先调研中国大陆官方可用的实时语音方案；优先原生实时语音到语音，没有合适方案时再评估流式 ASR → 文本 LLM → 流式 TTS。

## Comments

本决策将“中国大陆稳定可用”从可选考量收紧为架构硬约束。
