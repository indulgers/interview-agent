# 定义产品目标与 MVP 边界

Type: grilling
Status: resolved
Blocked by:

## Question

这个产品的用途、第一版成功标准、用户范围、面试方式、数字人和数据保存边界是什么？

## Answer

- 用途是 AI 模拟面试训练，不是真实面试辅助。
- MVP 是本机运行的单用户 Web 应用，不做登录、注册和多用户。
- 候选人完成固定 45 分钟的中文“Node.js 全栈 + AI Agent”模拟面试。
- 难度按 1–3 年经验、能独立交付业务功能的工程师校准。
- 面试从固定候选人画像中的真实项目出发，追问 Node.js 全栈与 AI Agent 能力；不做简历上传。
- AI 面试官专业克制、略有压力，会追问或礼貌打断，面试中不提示答案，指导统一放在会后反馈。
- 候选人摄像头只本地预览，不上传、录像或分析。
- 数字人使用固定头像和闭嘴/张嘴状态动画，不做 3D 或精确唇形。
- 语音支持双向打断，并保留手动“结束回答”的降级入口。
- 历史保存会话元数据、文字转写、会后反馈和内容版本，不保存音频或视频。
